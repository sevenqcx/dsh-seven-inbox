# Seven 收件箱 安装说明

适用插件：`dsh-seven-inbox`（中文名「Seven 收件箱」）
当前版本：v1.0.2
适用宿主：DeepSeek Harness 0.2.2-rc.1 及以上（0.2.x 系列）

---

## 一、这个插件做什么

Seven 收件箱把侧边栏的会话列表换成一个「按注意力排序的收件箱」：等待你确认或回答的会话排在前面，正在跑的会话收进底部悬浮卡片，暂缓和收尾的会话各归一组，跑完的任务可以一键收尾并撤销。

除了会话列表这一块，其余都保持 DSH 原生样子：顶栏、新建会话、插件入口、底栏、浅色与深色主题全部不动。装好后你会看到：

- 侧边栏顶部是「收件箱」标题、项目筛选徽标，右侧依次是搜索、视图选项、添加项目；
- 会话按「运行中 / 已收尾」等分组显示，运行中的会话有脉冲蓝点和计数；
- 顶部「视图选项」里可以在「收件箱 / 按工作区 / 按工作区树 / 单列表」之间直接来回切换，随时回到原生列表。

插件不联网、不上传任何数据；你选的筛选和视图偏好只存在本机浏览器里。

---

## 二、安装前须知

1. 安装完成后需要**完整退出 DeepSeek Harness 再重新打开**（只按刷新不够），插件才会生效。
2. 安装过程中如果宿主提示「需要确认依赖版本」，属正常的版本区间提示，按提示确认即可。
3. 本插件与其它「收件箱类」插件（例如 `dsh-t3-inbox`）同时启用时会互相抢侧边栏，同一时间只保留一个。

## 三、安装方式（三种任选其一）

### 方式一：按包名安装（推荐）

从 npm 安装，不需要额外的构建脚本授权，升级也最省事。

1. 打开 DeepSeek Harness，进入「插件」页面；
2. 选择「添加插件」；
3. 输入包名：

   ```
   dsh-seven-inbox
   ```

4. 安装并启用；
5. 完整退出并重新打开 DeepSeek Harness。

命令行等价写法：

```sh
dsh plugin add dsh-seven-inbox
```

### 方式二：按仓库地址安装

从 GitHub 仓库安装，适合想跟着主分支最新代码走的情况。

1. 「插件」页面选择「添加插件」；
2. 输入仓库地址：

   ```
   https://github.com/sevenqcx/dsh-seven-inbox
   ```

3. 安装并启用；
4. 完整退出并重新打开 DeepSeek Harness。

命令行等价写法：

```sh
dsh plugin add https://github.com/sevenqcx/dsh-seven-inbox
```

### 方式三：下载发布包安装（指定版本或离线）

适合需要固定某个版本、或者机器访问不了 npm 的情况。

1. 打开[发布页](https://github.com/sevenqcx/dsh-seven-inbox/releases)，下载对应版本的安装包，例如 `dsh-seven-inbox-1.0.2.tgz`；
2. 在「添加插件」里填入安装包地址，或在本机执行：

   ```sh
   dsh plugin add https://github.com/sevenqcx/dsh-seven-inbox/releases/download/v1.0.2/dsh-seven-inbox-1.0.2.tgz
   ```

3. 安装并启用；
4. 完整退出并重新打开 DeepSeek Harness。

注意：下载链接里的版本号（`v1.0.2`）和文件名里的版本号（`1.0.2`）必须属于同一个版本，混用会下载失败。

## 四、安装后怎么确认成功

重新打开 DeepSeek Harness 后，按顺序看三处：

1. **侧边栏**：原来的工作区列表变成收件箱，能看到「运行中」「已收尾」等分组；
2. **设置**：设置里多出一项「收件箱」，里面有「侧栏视图」可以选择「收件箱视图」或「工作区视图」；
3. **顶部右侧**：「视图选项」图标点开后，第一组「分组方式」里能看到「收件箱」，并且处于勾选状态。

三处都对上，说明安装成功。有任意一处没出现，请对照下一节排查。

---

## 五、升级、切回原生与卸载

**升级到新版本**：按第三节任意一种方式重新安装一遍即可，装完同样要完整退出再打开。你的筛选和视图偏好在升级后保留。

**随时切回原生列表**（两种入口，效果相同）：

- 顶部「视图选项」→「按工作区」；
- 或 设置 → 收件箱 → 侧栏视图 →「工作区视图」。

想再切回来，在同一个菜单里选「收件箱」即可，两个方向都能来回切换。

**卸载**：在「插件」页面停用或移除 `dsh-seven-inbox`，然后完整退出并重新打开。卸载后侧边栏自动恢复成 DSH 原生的工作区列表，会话数据不受影响。

## 六、常见问题

**装完侧边栏没有任何变化**
先确认是否完整退出并重新打开过；再确认插件处于启用状态。如果之前装过其它收件箱类插件，先停用它们，避免同时接管侧边栏。

**提示宿主依赖版本不满足**
说明当前的 DeepSeek Harness 版本不在插件支持区间内。两条路：把 DeepSeek Harness 升级到 0.2.2-rc.1 以上，或改装与当前版本匹配的旧版插件。

**按包名安装失败**
多为网络或 npm 源问题。改用「方式二：按仓库地址安装」或「方式三：下载发布包」即可，功能完全一样。

**侧边栏出现两个收件箱入口**
说明同时启用了两个同类插件。在「插件」页面停用其中一个，然后重启。

**找不到某个会话**
先清空顶部的项目筛选（点筛选徽标 →「全部」）；再确认视图选项里的分组方式和「筛选会话」是不是把已归档的会话隐藏了。

**颜色和宿主的深浅色不一致**
插件跟随宿主主题，不需要单独设置。如果你装过第三方主题插件，切换一次主题或重启即可重新对齐。
